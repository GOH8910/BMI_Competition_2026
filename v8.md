## 0. Problem Statement

Decode the two-dimensional hand position $(x(t), y(t)) \in \mathbb{R}^2$ of a macaque monkey from a population of $N = 98$ simultaneously recorded neural units. Each unit provides a binary spike train $s_i(t) \in \{0,1\}$ at 1 ms resolution, $i = 1,\ldots,98$. The decoder is **strictly causal**: at evaluation time $t$, only the history $\{s_i(\tau) : \tau \leq t\}$ may be used. Hand position is reported in mm. The scoring oracle evaluates decoded positions every 20 ms, starting at $t = 320$ ms (after sufficient data has accumulated), then $t = 340, 360, \ldots$ up to end-of-trial. The competition metric is root-mean-squared error (RMSE) in cm over all scored timepoints across all test trials.

Formally, we seek a function:

$$\hat{\mathbf{y}}(t) = f\!\left(\{s_i(\tau)\}_{i=1,\ldots,N}^{\tau \leq t},\ \mathbf{s}_0\right) \in \mathbb{R}^2$$

where $\mathbf{s}_0 \in \mathbb{R}^2$ is the known trial start hand position (provided by the test harness).

The eight reaching directions in the training set correspond to angles:

$$\theta_k = \frac{\{30,\ 70,\ 110,\ 150,\ 190,\ 230,\ 310,\ 350\}}{180}\pi, \quad k = 1,\ldots,8$$

## 1. Spike Preprocessing — Square Root Count Transform

The raw spike train is partitioned into non-overlapping windows of length $L = 80$ ms. For window index $w$ and neuron $i$, the spike count feature is:

$$f_i^{(w)} = \sqrt{\sum_{t=(w-1)L+1}^{wL} s_i(t)}, \quad w = 1, 2, \ldots, W_{\max}$$

This yields a feature matrix $\mathbf{F} \in \mathbb{R}^{N \times W_{\max}}$ per trial, where $W_{\max} = \lfloor T_{\min} / L \rfloor$ and $T_{\min}$ is the length of the shortest trial.

**Rationale for the square root transform.** Cortical spike counts in a fixed window are approximately Poisson-distributed. If a count $c \sim \text{Poisson}(\lambda)$, then the variance-stabilising (Anscombe) transform $\sqrt{c}$ satisfies $\text{Var}(\sqrt{c}) \approx \frac{1}{4}$ regardless of $\lambda$. This makes the feature distribution more homoscedastic, which is a prerequisite assumption of the linear discriminant analysis and ridge regression steps downstream.

The feature vector for trial $n$, direction $k$, window $w$ is therefore:

$$\mathbf{f}_{n,k}^{(w)} = \left[\sqrt{\sum_{t=(w-1)L+1}^{wL} s_{1,n,k}(t)},\ \ldots,\ \sqrt{\sum_{t=(w-1)L+1}^{wL} s_{N,n,k}(t)}\right]^\top \in \mathbb{R}^N$$

> Code reference: `sqrt(sum(sp(:, ts:te), 2))'` — `positionEstimatorTraining8.m` Step 1 and `positionEstimator8.m` Steps 1, 3

## 2. Direction Classification via Regularised Window-wise LDA

### 2.1 Per-Window LDA Classifier

A separate Linear Discriminant Analysis classifier is trained independently for each window $w = 1, \ldots, W_{\max}$. This allows the classifier to exploit the distinct temporal structure of neural responses within each 80 ms epoch.

The class mean vector for direction $k$ at window $w$ is:

$$\boldsymbol{\mu}_k^{(w)} = \frac{1}{N_{\text{train}}} \sum_{n=1}^{N_{\text{train}}} \mathbf{f}_{n,k}^{(w)} \in \mathbb{R}^N$$

The pooled within-class scatter matrix (normalised by degrees of freedom) is:

$$S_w = \frac{1}{N_{\text{train}} K - K} \sum_{k=1}^{K} \sum_{n=1}^{N_{\text{train}}} \left(\mathbf{f}_{n,k}^{(w)} - \boldsymbol{\mu}_k^{(w)}\right)\left(\mathbf{f}_{n,k}^{(w)} - \boldsymbol{\mu}_k^{(w)}\right)^\top \in \mathbb{R}^{N \times N}$$

where $K = 8$ directions and $N_{\text{train}} = 82$ (training split, 100 trials total per angle with some reserved for validation).

### 2.2 Shrinkage Regularisation (Ledoit–Wolf Style)

With $N = 98$ neurons and only $N_{\text{train}} = 82$ trials per class, the within-class scatter matrix $S_w$ is rank-deficient (rank at most $N_{\text{train}} K - K = 648$, but the $98 \times 98$ matrix is underdetermined from any single class). A shrinkage estimator is applied to produce a well-conditioned inverse:

$$\hat{S}_w = (1 - \alpha) S_w + \alpha \cdot \frac{\operatorname{tr}(S_w)}{N} \mathbf{I}_N$$

with regularisation strength $\alpha = 0.45$. This is the convex combination of the sample covariance $S_w$ and a scaled identity whose scale is chosen to match the average eigenvalue $\operatorname{tr}(S_w)/N$. The choice $\alpha = 0.45$ was tuned empirically and represents substantial regularisation, reflecting the high-dimensional, limited-sample regime.

The resulting estimator is related to the oracle-approximating shrinkage estimator of Ledoit and Wolf (2004), which minimises the expected Frobenius error between the estimator and the true population covariance.

The inverse $\hat{S}_w^{-1}$ is precomputed and stored at training time.

> Code reference: `Sw = (1-alpha_reg)*Sw + alpha_reg*(trace(Sw)/nNeurons)*eye(nNeurons); winLDA(w).SwInv = inv(Sw)` — `positionEstimatorTraining8.m` Step 1

### 2.3 Log-Posterior Accumulation

At inference with $W_{\text{avail}} = \lfloor T / L \rfloor$ complete windows available (capped at $W_{\max}$), the log-posterior for direction $k$ is accumulated as a sum of per-window log-likelihoods under a multivariate Gaussian model with shared regularised covariance:

$$\log P(k) \mathrel{+}= -\frac{1}{2} \left(\mathbf{f}^{(w)} - \boldsymbol{\mu}_k^{(w)}\right)^\top \hat{S}_w^{-1} \left(\mathbf{f}^{(w)} - \boldsymbol{\mu}_k^{(w)}\right), \quad w = 1, \ldots, W_{\text{avail}}$$

This is equivalent to a Gaussian Naive Bayes classifier with common within-class covariance across all windows, with uniform class priors $P(k) = 1/K$. The quadratic form $(\mathbf{f} - \boldsymbol{\mu}_k)^\top \hat{S}_w^{-1} (\mathbf{f} - \boldsymbol{\mu}_k)$ is the Mahalanobis distance from $\mathbf{f}$ to class $k$ in the metric defined by $\hat{S}_w$.

### 2.4 Temperature Scaling

A temperature parameter $\tau$ modulates the sharpness of the posterior. It decreases linearly as more windows become available:

$$\tau = \tau_{\text{early}} + (\tau_{\text{late}} - \tau_{\text{early}}) \cdot \frac{W_{\text{avail}} - 4}{\max(W_{\max} - 4,\ 1)}, \quad \tau \geq 0.5$$

with $\tau_{\text{early}} = 6.0$ and $\tau_{\text{late}} = 0.5$. The temperature-scaled posterior is computed via softmax:

$$P(k) = \frac{\exp(\log P(k) / \tau)}{\sum_{k'=1}^{K} \exp(\log P(k') / \tau)}$$

For numerical stability, $\log P(k) \leftarrow \log P(k) - \max_{k'} \log P(k')$ before exponentiation. High temperature early in the trial (when few windows have been observed) produces a soft, near-uniform posterior that hedges against premature misclassification. Low temperature late in the trial produces a sharply-peaked posterior, converging toward hard classification.

The best-classified direction is $k^* = \arg\max_k P(k)$.

> Code reference: `temp = tempEarly + (tempLate-tempEarly)*(nAvailWin-4)/max(maxNWin-4,1); P = softmax(logP/temp)` — `positionEstimator8.m` Steps 1–2

## 3. Feature Vector Construction

For position regressors and KNN retrieval, a concatenated multi-window feature vector is assembled. The number of feature windows is:

$$W_{\text{feat}} = \min\!\left(\max(4,\ W_{\text{avail}}),\ W_{\max}\right)$$

The concatenated feature vector is:

$$\boldsymbol{\phi} = \left[\mathbf{f}^{(1)\top},\ \mathbf{f}^{(2)\top},\ \ldots,\ \mathbf{f}^{(W_{\text{feat}})\top}\right]^\top \in \mathbb{R}^{N \cdot W_{\text{feat}}}$$

For KNN distance computation, later windows are upweighted by a quadratic recency scheme. The weight for all neurons in window $w$ is $\rho_w = (w / W_{\text{feat}})^2$, giving the recency-weighted squared distance:

$$d_{\text{recency}}(n) = \sum_{w=1}^{W_{\text{feat}}} \rho_w \cdot \left\|\boldsymbol{\phi}_w^{(n)} - \boldsymbol{\phi}_w^{\text{test}}\right\|^2 = \sum_{w=1}^{W_{\text{feat}}} \left(\frac{w}{W_{\text{feat}}}\right)^2 \left\|\mathbf{f}_w^{(n)} - \mathbf{f}_w^{\text{test}}\right\|^2$$

This reflects the intuition that the most recent neural activity is most informative about the animal's current position. Earlier windows (when direction intent may not yet be fully expressed in the population response) are downweighted.

> Code reference: `testFeat = [sqrt-counts window 1, ..., window W_feat]; winWeights = (ww/nFeatWin).^2` — `positionEstimator8.m` Step 3

## 4. Kernel PCA Regression (per direction, per window count)

For each direction $k \in \{1,\ldots,8\}$ and window count $n_w \in \{4,\ldots,W_{\max}\}$, a kernel PCA regression model is trained.

### 4.1 Feature Matrix and Centring

Let $X \in \mathbb{R}^{N_{\text{train}} \times (N \cdot n_w)}$ be the stacked feature matrix over all training trials, where row $n$ is $\boldsymbol{\phi}^{(n)\top}$. The row-mean is $\bar{\mathbf{x}} = \frac{1}{N_{\text{train}}} \sum_n \boldsymbol{\phi}^{(n)}$. The centred matrix is:

$$X_c = X - \mathbf{1}_{N_{\text{train}}} \bar{\mathbf{x}}^\top \in \mathbb{R}^{N_{\text{train}} \times (N \cdot n_w)}$$

### 4.2 Kernel Matrix and Eigendecomposition

The linear kernel (Gram) matrix is:

$$K = X_c X_c^\top \in \mathbb{R}^{N_{\text{train}} \times N_{\text{train}}}$$

This is the inner-product kernel $K_{mn} = \langle X_c^{(m)},\ X_c^{(n)} \rangle$ in the original feature space. The eigendecomposition is:

$$K = V \Lambda V^\top, \quad V^\top V = I_{N_{\text{train}}}, \quad \Lambda = \operatorname{diag}(\lambda_1 \geq \lambda_2 \geq \ldots \geq \lambda_{N_{\text{train}}})$$

The key computational advantage: $K$ is $N_{\text{train}} \times N_{\text{train}}$ (at most $82 \times 82$), whereas the direct covariance in feature space would be $(N \cdot n_w) \times (N \cdot n_w)$ (up to $98 \times 7 = 686$ dimensions). The kernel trick avoids explicitly forming the large covariance.

Retaining the top $p = \min(32, \#\{\lambda_i > 10^{-6}\})$ eigenvectors, the kernel PCA scores are:

$$Z = V_{:,1:p} \cdot \operatorname{diag}\!\left(\sqrt{\lambda_1}, \ldots, \sqrt{\lambda_p}\right) \in \mathbb{R}^{N_{\text{train}} \times p}$$

Row $n$ of $Z$ is the projection of training trial $n$ onto the top-$p$ principal directions in the feature space.

### 4.3 startHandPos Augmentation

The trial start position $\mathbf{s}_n = \mathbf{h}_n(1) \in \mathbb{R}^2$ (known at inference from `test_data.startHandPos`) is appended as an additional feature after centring:

$$\tilde{Z} = \left[Z,\ S_c\right] \in \mathbb{R}^{N_{\text{train}} \times (p+2)}, \quad S_c = S - \mathbf{1}\bar{\mathbf{s}}^\top$$

where $S \in \mathbb{R}^{N_{\text{train}} \times 2}$ has row $n$ equal to $\mathbf{s}_n^\top$ and $\bar{\mathbf{s}}$ is the mean start position. Although trials within a given direction class tend to begin from similar hand positions, there is residual variation that introduces ambiguity when regressing to absolute position targets. Including $\mathbf{s}_n$ allows the regression to partially account for this.

### 4.4 Ridge Regression to Absolute Position

For each evaluation time $t_e \in \{320, 340, \ldots, 800\}$ ms, the target matrix is:

$$Y(t_e) \in \mathbb{R}^{N_{\text{train}} \times 2}, \quad Y_{n,:}(t_e) = \mathbf{h}_n(t_e)^\top \quad \text{(absolute hand position)}$$

The mean-centred target is $Y_c(t_e) = Y(t_e) - \mathbf{1}\bar{\mathbf{y}}(t_e)^\top$. The ridge regression coefficient matrix is:

$$\hat{B}(t_e) = \left(\tilde{Z}^\top \tilde{Z} + \lambda I_{p+2}\right)^{-1} \tilde{Z}^\top Y_c(t_e) \in \mathbb{R}^{(p+2) \times 2}$$

with $\lambda = 20$ (ridge penalty). At inference, the test kernel score vector is computed as:

$$\mathbf{k}_{\text{test}} = X_c\, (\boldsymbol{\phi}_{\text{test}} - \bar{\mathbf{x}})^\top \in \mathbb{R}^{N_{\text{train}}}$$

$$\tilde{\mathbf{z}}_{\text{test}} = \left[\frac{V_{:,1:p}^\top \mathbf{k}_{\text{test}}}{\sqrt{\max(\lambda_{1:p}, 10^{-6})}},\ (\mathbf{s}_{\text{test}} - \bar{\mathbf{s}})^\top\right] \in \mathbb{R}^{1 \times (p+2)}$$

The predicted absolute position is then:

$$\hat{\mathbf{y}}_{\text{PCA},k}(t) = \tilde{\mathbf{z}}_{\text{test}}\, \hat{B}(t_{e^*})^\top + \bar{\mathbf{y}}(t_{e^*})$$

where $t_{e^*} = \arg\min_{t_e} |t_e - t|$ is the nearest pre-stored evaluation time.

> Code reference: `K=Xc*Xc'; [V,D]=eig(K); scores = V*sqrt(diag(lambda)); beta = (ZtZ + lambda*I)\(Z'*Yc)` — `positionEstimatorTraining8.m` Step 3

## 5. Per-Direction Causal Ridge Regression

A second regression model is trained per direction $k$, using a richer time-varying causal feature vector that includes both windowed and cumulative spike counts.

### 5.1 Feature Vector

At evaluation time $t$, the ridge feature vector $\mathbf{r}(t) \in \mathbb{R}^{4N + N + N + 1 + 2}$ is constructed from five components:

$$\mathbf{r}(t) = \left[\underbrace{\boldsymbol{\phi}_{1:4}}_{\substack{\text{first 4 windows} \\ \in\,\mathbb{R}^{4N}}},\ \underbrace{\sqrt{\sum_{\tau=\max(1,\,t-79)}^{t} \mathbf{s}(\tau)}}_{\substack{\text{current 80ms window} \\ \in\,\mathbb{R}^N}},\ \underbrace{\frac{\sqrt{\sum_{\tau=1}^{t} \mathbf{s}(\tau)}}{\sqrt{t/80}}}_{\substack{\text{normalised cumulative} \\ \in\,\mathbb{R}^N}},\ \underbrace{\frac{t}{800}}_{\substack{\text{time} \\ \in\,\mathbb{R}}},\ \underbrace{\mathbf{s}_0}_{\substack{\text{start position} \\ \in\,\mathbb{R}^2}}\right]$$

The first 4 windows ($4N$ features) capture the full observed neural trajectory from trial onset. The current 80 ms window provides local firing rate information. The normalised cumulative count $\sqrt{\sum_\tau s_i(\tau)} / \sqrt{t/80}$ is a normalised estimate of the average firing rate over the entire trial, invariant to the evaluation time $t$. The time feature $t/800$ allows the regressor to model non-stationarity in position over the trial.

### 5.2 Standardisation and Ridge Solution

All features are standardised element-wise across all training observations:

$$\tilde{\mathbf{r}} = \frac{\mathbf{r} - \boldsymbol{\mu}_r}{\boldsymbol{\sigma}_r}$$

where $\boldsymbol{\mu}_r$ and $\boldsymbol{\sigma}_r$ are the sample mean and standard deviation of each feature dimension across the training set. Features with $\sigma < 10^{-8}$ are left unchanged (no division by near-zero variance).

Training targets $H_k \in \mathbb{R}^{M \times 2}$ stack the absolute hand positions at all evaluation times for all training trials of direction $k$:

$$H_k = \begin{bmatrix} \mathbf{h}_{1,k}(320)^\top \\ \mathbf{h}_{1,k}(340)^\top \\ \vdots \\ \mathbf{h}_{N_{\text{train}},k}(T_{\max})^\top \end{bmatrix}, \quad \tilde{R}_k = \begin{bmatrix} \tilde{\mathbf{r}}_{1,k}(320)^\top \\ \tilde{\mathbf{r}}_{1,k}(340)^\top \\ \vdots \end{bmatrix}$$

The ridge solution is:

$$\hat{\beta}_k = \left(\tilde{R}_k^\top \tilde{R}_k + \lambda_r I\right)^{-1} \tilde{R}_k^\top \left(H_k - \bar{\mathbf{h}}_k \mathbf{1}^\top\right) \in \mathbb{R}^{(6N+3) \times 2}$$

with $\lambda_r = 650$. At inference:

$$\hat{\mathbf{y}}_{\text{ridge},k}(t) = \left(\tilde{\mathbf{r}}_{\text{test}}(t)\, \hat{\beta}_k\right)^\top + \bar{\mathbf{h}}_k$$

> Code reference: `Xn=(X-Xm)./Xs; beta=(Xn'*Xn + ridgeLambda*eye(nFeat))\(Xn'*(Y-Ym))` — `positionEstimatorTraining8.m` Step 4

## 6. KNN Trajectory Retrieval

### 6.1 Distance and Gaussian Kernel Weights

For the best-classified direction $k^*$, the $K_{k^*}$ nearest training trials are retrieved by recency-weighted Euclidean distance in feature space:

$$d_n = \sum_{w=1}^{W_{\text{feat}}} \left(\frac{w}{W_{\text{feat}}}\right)^2 \left\|\mathbf{f}_w^{(n)} - \mathbf{f}_w^{\text{test}}\right\|^2, \quad n = 1, \ldots, N_{\text{train}}$$

The $K_{k^*}$ trials with smallest $d_n$ form the neighbourhood $\mathcal{N}$. Gaussian kernel weights are computed with bandwidth equal to the median nearest-neighbour distance:

$$w_n = \frac{\exp(-d_n \,/\, 2\hat{\sigma}^2)}{\sum_{j \in \mathcal{N}} \exp(-d_j \,/\, 2\hat{\sigma}^2)}, \quad \hat{\sigma}^2 = \operatorname{median}_{j \in \mathcal{N}}(d_j) + \varepsilon$$

The bandwidth adapts to local data density: in crowded regions $\hat{\sigma}$ is small (sharp kernel), in sparse regions it is large (broad averaging). This is related to variable-bandwidth kernel regression.

### 6.2 Two KNN Predictions

Two distinct trajectory estimates are derived from the neighbourhood $\mathcal{N}$:

**Absolute KNN prediction** — weighted average of retrieved training trajectories at the current time:

$$\hat{\mathbf{y}}_{\text{KNN-abs}}(t) = \sum_{n \in \mathcal{N}} w_n\, \mathbf{h}_n(t)$$

**Displacement KNN prediction** — displacement from training trial's own start position is transferred to the test trial's start position:

$$\hat{\mathbf{y}}_{\text{KNN-disp}}(t) = \sum_{n \in \mathcal{N}} w_n \left[\mathbf{s}_0 + \left(\mathbf{h}_n(t) - \mathbf{h}_n(1)\right)\right]$$

The displacement prediction anchors to the known test start position $\mathbf{s}_0$, eliminating any systematic bias from variation in starting locations across training trials.

> Code reference: `dists = recency-weighted ||phi_test - phi_train||^2; wts = exp(-dists/(2*sigma)); knnDispPos = startPos + (hpT - knnStartK)` — `positionEstimator8.m` Step 4

## 7. Five-Way Soft Blend

Five position predictions are computed and combined. The soft direction probability vector $P(k)$ distributes credit across all directions rather than committing hard to the MAP estimate.

| Predictor | Formula |
|-----------|---------|
| Soft PCA | $\hat{\mathbf{y}}_{\text{PCA}} = \sum_{k=1}^{K} P(k)\, \hat{\mathbf{y}}_{\text{PCA},k}(t)$ |
| Soft trajectory | $\hat{\mathbf{y}}_{\text{traj}} = P(k^*)\,\hat{\mathbf{y}}_{\text{KNN-abs}} + \sum_{k \neq k^*} P(k)\, \bar{\mathbf{h}}_k(t)$ |
| Soft ridge | $\hat{\mathbf{y}}_{\text{ridge}} = \sum_{k=1}^{K} P(k)\, \hat{\mathbf{y}}_{\text{ridge},k}(t)$ |
| Soft displacement | $\hat{\mathbf{y}}_{\text{disp}} = \mathbf{s}_0 + \sum_{k=1}^{K} P(k)\, \bar{\boldsymbol{\delta}}_k(t)$ |
| KNN displacement | $\hat{\mathbf{y}}_{\text{KNN-disp}}$ (from §6.2) |

These are combined hierarchically. Let $w_{\text{pca},k^*}$ and $\alpha_{r,k^*}$ be the per-direction hyperparameters for the best direction:

$$\hat{\mathbf{y}}_{\text{base}} = w_{\text{pca}} \cdot \hat{\mathbf{y}}_{\text{PCA}} + (1 - w_{\text{pca}}) \cdot \hat{\mathbf{y}}_{\text{traj}}$$

$$\hat{\mathbf{y}}_{\text{neural}} = (1 - \alpha_r) \cdot \hat{\mathbf{y}}_{\text{base}} + \alpha_r \cdot \hat{\mathbf{y}}_{\text{ridge}}$$

The displacement prediction used in the final blend is purely the KNN displacement:

$$\hat{\mathbf{y}}_{\text{disp-pred}} = \hat{\mathbf{y}}_{\text{KNN-disp}}$$

The final blend weight $w_d$ is time-varying:

$$w_d = w_{d,\text{early}} (1 - \xi) + w_{d,\text{late}} \cdot \xi, \quad \xi = \frac{W_{\text{avail}} - 4}{\max(W_{\max} - 4,\ 1)} \in [0,1]$$

with $w_{d,\text{early}} = 0.20$ and $w_{d,\text{late}} = 0.01$.

**Uncertainty-aware displacement boost.** When the classifier is uncertain about direction ($P(k^*) < 0.65$), the displacement predictors (which are anchored to the known start position) are more trustworthy than regression models that may be evaluated far from their training manifold. The weight is boosted:

$$w_d \mathrel{+}= \max\!\left(0,\ 5.0 \cdot (0.65 - P(k^*))\right)$$

$w_d$ is then capped at 0.85. The final blended position is:

$$\hat{\mathbf{y}}_{\text{blend}} = (1 - w_d) \cdot \hat{\mathbf{y}}_{\text{neural}} + w_d \cdot \hat{\mathbf{y}}_{\text{disp-pred}}$$

> Code reference: `basePos = pcaW*softPCA + (1-pcaW)*softTraj; neuralPos = (1-alpha)*basePos + alpha*softRidge; pos = (1-dispWeight)*neuralPos + dispWeight*knnDispPos` — `positionEstimator8.m` Steps 5–6

## 8. Kinematic Velocity Blend

When two or more previously decoded positions are available from `test_data.decodedHandPos`, a kinematic prediction is computed from the most recent decoded velocity:

$$\hat{\mathbf{v}}(t) = \frac{\hat{\mathbf{y}}(t-20) - \hat{\mathbf{y}}(t-40)}{20} \quad \text{(mm/ms)}$$

$$\hat{\mathbf{y}}_{\text{kin}}(t) = \hat{\mathbf{y}}(t-20) + \hat{\mathbf{v}}(t) \cdot 20$$

This is blended with the neural estimate using a time-varying kinematic weight $\gamma_{\text{kin}}$:

$$\hat{\mathbf{y}} = (1 - \gamma_{\text{kin}}) \cdot \hat{\mathbf{y}}_{\text{blend}} + \gamma_{\text{kin}} \cdot \hat{\mathbf{y}}_{\text{kin}}$$

$$\gamma_{\text{kin}} = \gamma_{\text{kin,early}} (1 - \xi) + \gamma_{\text{kin,late}} \cdot \xi$$

with $\gamma_{\text{kin,early}} = 0.22$ and $\gamma_{\text{kin,late}} = 0.04$. Early in the trial (before enough windows have accumulated for confident classification), the kinematic prediction provides continuity. Late in the trial, when neural regression is more reliable, the kinematic contribution is reduced.

> Code reference: `vel = (decodedHandPos(:,end) - decodedHandPos(:,end-1))/20; kinematicPos = prevPos + vel*20; pos = (1-kinW)*pos + kinW*kinematicPos` — `positionEstimator8.m` Step 7

## 9. Adaptive EMA Smoothing and Outlier Clamping

### 9.1 Adaptive Exponential Moving Average

The position estimate is smoothed against the previous decoded position using an exponential moving average with time-varying coefficient:

$$\hat{\mathbf{y}}_{\text{out}} = (1 - \gamma) \cdot \hat{\mathbf{y}} + \gamma \cdot \hat{\mathbf{y}}(t-20)$$

$$\gamma = \gamma_{\text{early}} + (\gamma_{\text{late}} - \gamma_{\text{early}}) \cdot \xi$$

with $\gamma_{\text{early}} = 0.05$, $\gamma_{\text{late}} = 0.00$. Early in the trial, moderate smoothing suppresses noise; late in the trial, smoothing is disabled to allow the regression to track fine trajectory detail.

### 9.2 Outlier Clamping

If the raw jump distance $\|\hat{\mathbf{y}} - \hat{\mathbf{y}}(t-20)\|$ exceeds a threshold $J_{\max} = 80$ mm (indicative of a transient direction misclassification), the smoothing coefficient is boosted proportionally:

$$\gamma \mathrel{+}= (\gamma_{\text{clamp}} - \gamma) \cdot \min\!\left(\frac{\|\hat{\mathbf{y}} - \hat{\mathbf{y}}(t-20)\| - J_{\max}}{J_{\max}},\ 1\right)$$

with $\gamma_{\text{clamp}} = 0.30$. This interpolates $\gamma$ from its scheduled value toward 0.30 as the jump excess grows, pulling the output back toward the previous decoded position and suppressing outlier jumps from brief misclassifications.

> Code reference: `jumpDist = norm(pos - prevPos); if jumpDist > maxJumpMm, excess = min((jumpDist-maxJumpMm)/maxJumpMm,1); gamma = gamma + (clampGamma-gamma)*excess` — `positionEstimator8.m` Step 7

## 10. Data-Driven Kalman Filter (Post-Processing Stage)

A linear Kalman filter operates over the 4D kinematic state $\mathbf{x}(t) = [x,\ y,\ v_x,\ v_y]^\top$. Its transition matrix $F$ is fit from training data rather than assumed from physics.

### 10.1 System Model

$$\mathbf{x}(t+\Delta t) = F\,\mathbf{x}(t) + \boldsymbol{\eta}(t), \quad \boldsymbol{\eta} \sim \mathcal{N}(\mathbf{0}, Q)$$

$$\mathbf{z}(t) = H\,\mathbf{x}(t) + \boldsymbol{\epsilon}(t), \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, R)$$

with $H = [I_2\ \mathbf{0}_{2\times2}]$ (observing only position). $\Delta t = 20$ ms.

### 10.2 Data-Driven Transition Matrix

$F$ is estimated by ordinary least squares from consecutive state pairs extracted from all training trajectories:

$$F = \left(\sum_t \mathbf{x}(t+\Delta t)\,\mathbf{x}(t)^\top\right)\left(\sum_t \mathbf{x}(t)\,\mathbf{x}(t)^\top + \varepsilon I\right)^{-1}$$

The process noise covariance $Q$ is the sample covariance of prediction residuals $\mathbf{x}(t+\Delta t) - F\,\mathbf{x}(t)$. The observation noise covariance is set to $R = \text{diag}(45,\ 45)$ mm$^2$ (approximate per-axis RMSE of the decoder), and is diagonal.

### 10.3 Kalman Predict–Update

At each evaluation step, the standard Kalman predict–update equations are applied:

$$\mathbf{x}^-(t) = F\,\mathbf{x}(t-\Delta t), \quad P^-(t) = F P(t-\Delta t) F^\top + Q$$

$$K_G = P^-(t) H^\top \left(H P^-(t) H^\top + R\right)^{-1}$$

$$\mathbf{x}(t) = \mathbf{x}^-(t) + K_G\left(\hat{\mathbf{y}}_{\text{out}}(t) - H\,\mathbf{x}^-(t)\right)$$

$$P(t) = (I - K_G H)\,P^-(t)$$

In the current deployed version the Kalman blend weight is set to 0.0 (disabled), so the Kalman filter is a no-op and the output of the EMA stage is the final prediction. The infrastructure is retained for future use.

> Code reference: `F_kalman = SSmix/(SScur + 1e-6*eye(4)); xK = xK_pred + KG*innov; PK = (I-KG*H)*PK_pred` — `positionEstimatorTraining8.m` Step 7 / `positionEstimator8.m` Step 8

## 11. Per-Direction Adaptive Hyperparameters

Each reaching direction $k$ is assigned a difficulty score measuring the RMS deviation of individual trial trajectories from the direction mean at evaluation timepoints:

$$d_k = \sqrt{\frac{1}{|\mathcal{T}_k|} \sum_{t \in \mathcal{T}_k} \sum_{n=1}^{N_{\text{train}}} \left\|\mathbf{h}_n^{(k)}(t) - \bar{\mathbf{h}}_k(t)\right\|^2}$$

where $\mathcal{T}_k = \{320, 340, \ldots, T_k\}$ is the set of evaluation times for direction $k$. The difficulty is normalised:

$$\tilde{d}_k = \frac{d_k - d_{\min}}{d_{\max} - d_{\min}} \in [0, 1]$$

where $d_{\min} = \min_k d_k$ and $d_{\max} = \max_k d_k$. Hyperparameters are then mapped linearly:

| Hyperparameter | Easy ($\tilde{d}_k = 0$) | Hard ($\tilde{d}_k = 1$) | Formula |
|---|---|---|---|
| KNN neighbours $K_k$ | 10 | 3 | $\text{round}(10 - 7\tilde{d}_k)$ |
| PCA weight $w_{\text{pca},k}$ | 1.00 | 1.00 | Fixed (all PCA) |
| Ridge alpha $\alpha_{r,k}$ | 0.25 | 0.35 | $0.25 + 0.10\tilde{d}_k$ |

For easy directions (tightly clustered trajectories), more KNN neighbours can be averaged without introducing large bias. For hard directions (high trial-to-trial variability), fewer neighbours are used to avoid averaging over dissimilar trajectories, and the ridge regressor is weighted more heavily as it generalises better in high-variance settings.
